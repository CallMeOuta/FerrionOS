# FerrionOS Memory Management (`rmm`)

Rust crate providing hardware memory management abstractions and a software-emulation testing mechanism for the FerrionOS kernel. Derived from the upstream project at the revision recorded in [`components/upstream.toml`](../../upstream.toml), under the license in [`../LICENSE`](../LICENSE).

Built as part of `components/kernel` with `CI=1 COOKBOOK_LOGS=true make r.kernel`. See [`components/kernel/README.md`](../README.md) and [`agents/skills/component-sources.md`](../../../agents/skills/component-sources.md) for build and VM verification commands.
